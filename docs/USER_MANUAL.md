# 📱 PedsRx 兒科常用藥快速查詢與劑量計算系統 - 臨床操作說明書

歡迎使用 **PedsRx**。本手冊旨在協助臨床醫師、住院醫師、實習醫師、專科護理師與臨床藥師快速掌握本系統的各項核心功能。

---

## 🎯 系統定位與目標

兒科病人體重跨度極大（從 2 kg 新生兒至 70 kg 青少年），用藥劑量絕大多數需依體重（mg/kg）或體表面積精準計算，且常面臨「單次劑量上限」、「每日劑量上限」、「年齡禁忌門檻」等多重限制。

**PedsRx** 旨在解決臨床以下痛點：
1. **防範計算錯誤**：輸入體重後，自動計算單次給藥毫升數（mL）、錠數（#）、包數（pk）或安瓿支數（amp）。
2. **自動警示極量**：當體重換算出的劑量撞到仿單或指引天花板時，立即亮起紅字警示（如 `⚠ 已達單次上限 1 顆`），防範超量開立。
3. **劑型混淆防護**：針對同名但劑型不同（如 Curam 口服水劑 vs 靜脈針劑）之藥品，以顯著視覺色塊與標籤區隔，防止處方混淆。

## 💡 詳細操作步驟

### 步驟一：設定病人體重
1. 進入系統後，首先點擊頂部 **「體重」** 輸入框。
2. 輸入病人目前體重（公斤，例如 `14.5`）。
   - **手機操作**：點擊輸入框會自動跳出數字小鍵盤。
   - **微調劑量**：可點擊 `[−]` 或 `[＋]` 按鈕以 1 kg 為單位微調體重。
3. 體重設定完成後，全站所有卡片的計算區塊會同步重新計算。

### 步驟二：查詢藥物
您可透過以下兩種方式找到目標藥物：

- **方式 A：關鍵字即時搜尋**
  - 在搜尋列輸入任何關鍵字，系統支援：
    - **藥品商品名**：如 `Curam`、`Voren`、`Sconin`、`Tamiflu`。
    - **藥品學名**：如 `amoxicillin`、`ibuprofen`、`oseltamivir`。
    - **適應症或症狀**：如 `中耳炎`、`AOM`、`發燒`、`氣喘`、`嘔吐`、`便秘`。
    - **劑型**：如 `針劑`、`栓劑`、`糖漿`、`懸液`。

- **方式 B：分類目錄切換**
  - **電腦版**：直接點擊左側導航選單中之分類（如 `呼吸道症狀 -> 氣喘`）。
  - **手機版**：點擊左上角 `[☰ 分類]` 按鈕，自左側抽屜選單中點選目標分類。

## 📊 藥物卡片資訊解讀指引

| 區塊名稱 | 視覺特徵 | 說明 |
| :--- | :--- | :--- |
| **藥物標題** | 粗體大字 + 劑型膠囊 | 標示商品名、學名、單一規格與給藥途徑（如 `針劑` 為淡紫色標籤）。 |
| **副標題** | 灰色小字 | 標示藥品濃度規格、適應症門檻（如 `>38.5°C 使用`）。 |
| **嚴重警語** | 紅底紅框 `⚠` | 標示重大安全警訊、仿單核准年齡限制或配方致命禁忌。 |
| **注意事項** | 橘底橘框 `※` | 標示臨床調劑、輸注時間、空腹/飯後或抗藥性分流建議。 |
| **主劑量計算列** | 淺藍色背景 + 超大粗體字 | **核心開立數字**（如 `10 mL`、`0.6 顆`），包含給藥頻次與上限警示。 |
| **次要附註列** | 灰色細線條列 | 輔助參考值（如對照之每日總劑量、累積 clavulanate 毫克數）。 |
| **速算公式** | 等寬標籤 `(BW/2) mL` | 提供臨床常規記憶用之速算公式。 |
| **臨床解說清單** | 圓點條列清單 | 匯整指引建議、分包泡製說明、換劑型對照表等實務指引。 |
| **實證文獻** | 底部藍色連結標籤 | 可直接點擊跳轉至原廠仿單、FDA/EMA 警訊、AAP 或 UpToDate 實證指引。 |

## 🎨 護眼主題切換

為避免臨床人員長時間看螢幕產生視覺疲勞，點擊右上角主題按鈕可即時切換：
1. **🌿 柔和護眼（預設）**：降低背景眩光，提供舒適冷灰對比。
2. **📖 暖米色調**：模擬溫暖紙質色調，適合低光照病房閱讀。
3. **🌙 深色夜間**：深邃藍黑底色，專為夜間值班與無反光需求打造。

## 📱 手機 App 化安裝教學 (PWA / 加到主畫面)

本系統支援現代 Web 行動瀏覽器，您可以將其「加入主畫面」，如同原生 App 般隨點隨用：

- **iOS (Safari)**：
  1. 以 Safari 開啟網址 `https://b8401121.github.io/Peds/`。
  2. 點擊瀏覽器底部的 **「分享」按鈕**（向上箭頭圖示）。
  3. 向下滾動並選擇 **「加入主畫面 (Add to Home Screen)」**。
  4. 點擊右上角「新增」，手機桌面即可產生專屬圖示。

- **Android (Chrome)**：
  1. 以 Chrome 開啟網址。
  2. 點擊右上角 **「⋮」選單按鈕**。
  3. 選擇 **「加到主畫面」** 或 **「安裝應用程式」** 即可。
